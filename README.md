# HaoLanguageLearn

English vocabulary trainer inside Obsidian: 250 decks / 5000 words, phonetics, Chinese glosses,
bilingual example sentences, spaced review and a mistake notebook.

**Paid plugin.** 7-day full-featured trial, then ¥49.9 one-time (lifetime updates).

## What's inside

- 250 decks of 20 words (beginner / intermediate / advanced by frequency)
- 3998 words come with example sentences (English + Chinese, Tatoeba CC-BY 2.0 FR)
- 41 practical grammar entries
- Quiz per deck; wrong answers go to a mistake notebook automatically
- Deck overview grid: 250 tiles show exactly how far you are

## Install

1. Open the plugin panel from the left ribbon ("语言学习")
2. Paste your licence code, or use **Import licence file**
3. 20 words a day, 10 minutes

## Privacy

Runs fully offline. No telemetry, no network calls except speaking via the system TTS.
